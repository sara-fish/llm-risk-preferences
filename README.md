# Supplementary Materials for *Human-Like Generalization of Risk Preferences*

This repo contains supplementary materials for the paper *Human-Like Generalization of Risk Preferences* ([link to working paper](https://sarafish.com/pdfs/20261006_Human-Like_Generalization_of_Risk_Preferences_in_LLMs.pdf)). The contents are:
* `prompts.md`: all prompts used in the experiments in the paper 
* `human_experiment_walkthrough.pdf`: walkthrough of both Experiment 1 and Experiment 2

Authors: [Sara Fish](https://sarafish.com/), [Felix Sosa](https://www.mit.edu/~fsosa/), [Sonia Murthy](https://soniamurthy.com/) 

Contact: [Sara Fish](https://sarafish.com/)
